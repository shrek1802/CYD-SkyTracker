CYD SkyTracker

Live aircraft on your ESP32 CYD touchscreen, with offline SD maps and phone Wi-Fi setup.

Developer preview. First-test USB firmware is available from GitHub Actions, but a public one-click web installer is not yet enabled. Screen/touch variants still need physical verification.

1. Identify your CYD

Board profile: cyd_2432s028r. Not physically verified. If you're unsure of the display controller, identify your board before flashing.

2. Flash the firmware

The final installer will use ESP Web Tools, so users can connect their CYD by USB and flash a signed, board-matched release from Chrome or Edge.

One-click install — coming soon

First-test USB flash guide

Please don't flash images for another screen model. The flash images currently come from GitHub CI, not published releases.

3. Set up using your phone

1. Power up

Look for the temporary SkyTracker setup Wi-Fi network on the screen.

2. Open setup

Connect your phone and browse to 192.168.4.1.

3. Track aircraft

Enter Wi-Fi and your home position. Tap a plane to see available flight details.
